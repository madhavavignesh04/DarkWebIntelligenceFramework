# Dark Web Intelligence Framework

An AI-powered cybersecurity intelligence framework for crawling, analyzing, categorizing, and risk-profiling web content through a Django-based dashboard.

## Features

- Recursive web crawling
- Tor-based access for authorized `.onion` research
- NLP-based entity extraction
- Sentiment analysis
- Content categorization
- Suspicious content profiling
- Risk score and risk-level classification
- Automated webpage screenshots
- AI-assisted content analysis
- Django web dashboard
- Analytics and risk distribution
- SQLite database
- Multi-threaded URL status checking

## Technologies

- Python
- Django
- BeautifulSoup
- Requests
- Tor
- spaCy
- NLTK
- Google Gemini AI
- Playwright
- SQLite
- HTML/CSS

## Dashboard

The system provides a dashboard to view:

- Crawled pages
- Categories
- Sentiment
- Risk scores
- Risk levels
- AI analysis
- Screenshots
- System analytics

## Purpose

This project is developed for academic cybersecurity research and authorized security analysis.

## Disclaimer

This framework should only be used on systems, websites, and content for which the user has permission to perform security research or analysis.
